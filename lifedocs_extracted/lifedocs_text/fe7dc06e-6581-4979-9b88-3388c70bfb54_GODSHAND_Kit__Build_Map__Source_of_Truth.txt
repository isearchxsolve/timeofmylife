2. The reference loader reads recursively.
comfy_client.py and render_motion.py
collect refs with glob("refs/jack/**/*", recursive=True) — so they reach into 
_inbox/ instead of reading only refs/jack/face/ .
3. _inbox sorts first, and only the first 5 refs are used. An underscore sorts
before letters, so the recursive list starts with the two _inbox images. The code
keeps refs[:5] , so Spider-Man and Joker became jack’s top-two identity
anchors, ahead of his real face.
And the safety net failed too: the identity-check gate ( _identity_score ) uses the 
same recursive glob, so it scored rendered frames against Spider-Man as if that
were jack — it did not just miss the drift, it approved it.
Net effect: the blueprint still was conditioned on Spider-Man/Joker → jack
animated as Spider-Man → the QC gate rubber-stamped it.
The fix
Immediate (done):
GODSHAND_MASTER.zip has every refs/*/_inbox/ folder deleted,
so the recursive glob can only find real face/body images.
Permanent (one-line, recommended): restrict the ref globs to the face/body
folders, never the parent. In comfy_client.py , render_motion.py ( _identity_score ),
and refs_for() , read refs/<char>/face/* (and /body/* ) instead of refs/<char>/**/* .
Then even if junk lands in _inbox again, it can never reach a render.
